# Shrooman Tycoon – Progress Report

## 📌 Project Description
Shrooman Tycoon is a tycoon style game made in C# usin' OOP.  
Player starts as a small gardener with almost nothing and slowly builds up a plant business.

Later in the game there will be more advanced stuff like kitchen, lab, prestige system and exotic mushrooms.

---

## ✅ What I Have Done So Far

### 🔧 Basic Structure (OOP)
I created basic classes for the game:
- `Player` – stores money and inventory
- `Seed` – has price, grow time and sell price
- `Plant` – represents planted seed and its growth
- `Garden` – handles planted plants and growin'
- `Game` – main game loop and logic

Everything is separated into classes so it can be expanded later.

---

### 🌱 Game Mechanics

#### ✔️ Economy
- player starts with money
- can buy seeds
- each seed has its own stats (price, grow time, sell price)

#### ✔️ Plantin'
- player can plant seeds from inventory
- planted seeds become plants in garden

#### ✔️ Growin' system
- plants grow every day
- each plant has progress (growth / max growth)
- when finished → plant is READY

#### ✔️ Sellin'
- player can sell ready plants
- gets money for each plant

#### ✔️ Day system
- player can skip day
- all plants grow when next day is used

---

### 🎮 UI
- console UI using Spectre.Console
- menu controlled by arrow keys
- green color theme (kinda hacker style)
- panel with player stats
- plant status showin' (growin / ready)
